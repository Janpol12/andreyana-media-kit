# Структура сайта — AndreYana Media Kit

Этот проект представляет собой современный одностраничный сайт-портфолио (Медиа Кит), созданный с использованием HTML5, Vanilla CSS и JavaScript. 

---

## 📂 Обзор файлов и папок

```text
/andreyana-site
├── index.html          # Главная страница (разметка, контент, SEO, мета-теги)
├── style.css           # Весь дизайн (адаптивная верстка, типографика, анимации)
├── script.js           # Функционал (галереи, плавный скролл, видео-плеер iPhone MAX)
├── favicon.svg         # Векторная иконка сайта (favicon)
├── sitemap.xml         # Карта сайта для индексации в Google/Yandex
├── robots.txt          # Инструкции для поисковых ботов
└── images/             # Директория со всеми медиа-ресурсами
    ├── portfolio_2026.mp4 # Основной шоурил (заглавное видео)
    ├── *.webp          # Фотографии (в современном формате для быстрой загрузки)
    └── *.mp4           # Видео-кейсы для рекламных проектов
```

---

## 🛠 Технологии
- **HTML5:** Семантическая верстка для лучшего SEO.
- **CSS3:** Использование Flexbox, CSS Grid и переменных для гибкого дизайна. 
- **Vanilla JS:** Отсутствие тяжелых библиотек обеспечивает высокую скорость работы.
- **GitHub Pages:** Автоматический хостинг и деплой.
