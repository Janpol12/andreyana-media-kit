Как установить Claude на компьютер

Для этого гайда нужен десктопный Claude с режимом Cowork. Вот как его поставить — занимает 3 минуты.

1
~1 минута
Скачай десктопное приложение Claude

Открой claude.ai/download в браузере и скачай версию для своей системы. Доступно для macOS и Windows.

Прямые ссылки для скачивания

macOS → claude.ai/download → «Download for Mac»

Windows → claude.ai/download → «Download for Windows»

Минимальные требования: macOS 12+ или Windows 10+, 4 ГБ RAM

Аккаунт Нужен аккаунт на claude.ai — зарегистрируйся бесплатно через Google или email. Базовый план бесплатный.
2
~1 минута
Установи приложение

После скачивания:

macOS

Открой скачанный .dmg файл → перетащи Claude в папку Applications → открой из Launchpad или Spotlight (Cmd+Пробел → «Claude»)

Windows

Запусти скачанный .exe установщик → нажми «Install» → после установки Claude появится на рабочем столе или в меню Пуск

3
~1 минута
Включи режим Cowork

Обычный Claude отвечает текстом. Cowork — это другой режим внутри десктопного приложения: он умеет создавать файлы, открывать браузер, запускать код. Именно его я использовала для сайта.

Как включить Cowork

1. Открой приложение Claude на компьютере
2. В левом меню найди раздел «Cowork» или иконку с рабочим столом
3. Нажми — откроется новый чат в режиме Cowork
4. Теперь можешь писать задания — Claude будет создавать файлы прямо на твоём компьютере

Важно Cowork — это не Claude Code (инструмент для разработчиков в терминале). Cowork — визуальный режим в десктопном приложении, специально для таких задач как наш сайт. Никакого программирования не нужно.

Пошаговый процесс
8 шагов от идеи
до живого сайта

Повторяй по порядку. Каждый шаг занимает от 10 минут до 2 часов — зависит от того, насколько ты перфекционист.

1
~15 минут
Ответь на 5 вопросов до того как открывать Claude

Это самый важный шаг, который все пропускают. Чем точнее ты знаешь что хочешь — тем меньше правок и переделок потом. Claude не умеет читать мысли, он работает с тем что ты ему даёшь.

Открой заметки и запиши:

Мои ответы перед стартом

1. Кто аудитория? Бренды и маркетологи, которые ищут UGC-мейкера

2. Какие разделы нужны? О нас · Фото · Видео · Мы в рекламе · Прайс · Контакт

3. Цвета бренда? Чёрный #0c0c0c · Золотой #c5a367 · Кремовый #f9f7f4

4. Какой тон? Дорого, кинематографично, без лишних слов

5. Что должен сделать посетитель? Написать в Telegram или WhatsApp

Про цвета Если у тебя ещё нет цветов бренда — возьми 2–3 цвета из своих фотографий. Посмотри что повторяется: тёплые тона, холодные, нейтральные. Используй сервис imagecolorpicker.com — загрузи фото и пипеткой возьми нужный цвет.

~20 минут
Напиши первый промпт — максимально конкретно

Открой Claude в Cowork-режиме. Теперь главное — не писать «сделай красивый сайт». Это даст тебе что-то общее и безликое. Нужна конкретика: структура, цвета, технологии, поведение.

Шаблон первого промпта — скопируй и адаптируй

«Создай одностраничный сайт-медиакит для [кто ты — UGC-мейкер / фотограф / дизайнер]. Цвета: основной [HEX], акцент [HEX], фон [HEX]. Шрифт: [Inter / Playfair / любой из Google Fonts]. Разделы: [перечисли]. Технологии: только HTML/CSS/JS, без фреймворков. Плавный скролл через Lenis CDN v1.0.42. Двуязычность RU/EN через data-атрибуты и кнопку переключения. Стиль: [опиши: минималистичный / тёплый / кинематографичный / editorial]. Навигация: фиксированная сверху с backdrop-blur. В конце раздел с прайсом — 3 пакета.»

Чем больше деталей — тем точнее результат. Можно добавить: «Вдохновение: сайты в стиле Bottega Veneta или Vogue» — Claude это понимает.
Хитрость После первого результата сразу открой его в браузере (просто перетащи файл index.html в окно Chrome). Смотри общее впечатление — не детали. Детали будешь чинить потом, итерация за итерацией.

Итерируй — описывай правки голосом

Вот где начинается магия. Ты смотришь на сайт, видишь что не нравится — и просто говоришь Claude что изменить. Никакого кода. Никаких технических знаний.

Вот реальные правки которые я делала:

Примеры реальных правок из чата

«Увеличь шрифт в карточках раздела "О нас" на 20%»

«Переименуй пункт навигации "Клиенты" в "Мы в рекламе" — везде, включая JS-переводы»

«Добавь новое видео: файл kofenya_misha.mp4, название "Кофейня MISSHA", поставь на 8-е место»

«Раздел с пакетами — удали полностью, оставь только три прайс-карточки»

«Сделай кнопку переключения языка более заметной — золотая рамка, не просто текст»

Распространённая ошибка Не пытайся исправить всё за один промпт. Лучше одна правка = один запрос. Так проще отследить что изменилось и откатить если что-то сломалось.

~30 минут
Сожми видео — это обязательно

Сырые видео с телефона или камеры весят 50–300 МБ. На GitHub лимит — 100 МБ на файл, и в целом тяжёлые видео убивают скорость загрузки сайта. ffmpeg решает это за пару минут.

Установить ffmpeg (macOS)
# Сначала установи Homebrew если его нет:
brew install ffmpeg
Сжать одно видео
ffmpeg -i input.mp4 -vcodec libx264 -crf 28 -preset slow output.mp4
Сжать всё видео в папке сразу
# Зайди в папку с видео:
cd ~/Downloads/твоя-папка/images

# Сжать все .mp4 файлы:
for f in *.mp4; do ffmpeg -i "$f" -vcodec libx264 -crf 28 -preset slow "compressed_$f"; done
Параметр crf crf 28 — хорошее качество для веба. crf 23 — выше качество, больше размер. crf 32 — ещё меньше файл, заметная потеря. Для большинства сайтов 28 — оптимально.

Создай репозиторий на GitHub

GitHub — это где живёт код твоего сайта. Создай бесплатный аккаунт на github.com, потом создай новый репозиторий (New repository). Назови его понятно: andreyana-media-kit или my-portfolio.

В терминале — одноразовая настройка
# Зайди в папку с сайтом
cd ~/Downloads/Agents/твоя-папка

# Инициализируй Git
git init
git add -A
git commit -m "first commit"

# Подключи к GitHub (URL берёшь из своего репозитория)
git remote add origin https://github.com/USERNAME/REPO.git
git push --set-upstream origin main
Ветка main, не master GitHub по умолчанию создаёт ветку main. Если у тебя создалась master — переименуй: git branch -m master main

Включи GitHub Pages — сайт онлайн

Это самый приятный момент. После одного клика твой сайт становится доступен в интернете по постоянной ссылке.

Как включить GitHub Pages

1. Открой репозиторий на github.com
2. Вкладка Settings → раздел Pages в левом меню
3. В поле Source выбери: Deploy from a branch
4. Branch: main → папка: / (root) → нажми Save
5. Подожди ~1 минуту → обнови страницу
6. Скопируй адрес: username.github.io/repo-name 🎉

Свой домен Хочешь адрес типа andreyana.ru вместо github.io? Купи домен на reg.ru или namecheap (~500–1500 ₽/год) и подключи через Settings → Pages → Custom domain. Инструкция есть в документации GitHub.
7
вечно :)
Обновляй сайт одной командой

Внёс правки с Claude, добавил новое видео, изменил прайс — один раз запускаешь команду и через минуту сайт обновлён в интернете. Больше ничего не нужно.

Команда обновления — запомни её навсегда
cd ~/Downloads/Agents/твоя-папка && git add -A && git commit -m "update" && git push
1 команда ~1 мин до обновления Бесплатно навсегда История изменений сохраняется
Лайфхак Добавь эту команду в алиас терминала, чтобы не набирать каждый раз:
alias deploy="cd ~/Downloads/Agents/твоя-папка && git add -A && git commit -m 'update' && git push"

Подключи Google Analytics

После того как сайт работает — добавь аналитику. Это бесплатно и даёт понять: сколько людей заходит, откуда, на каком разделе уходят. Без этого работаешь вслепую.

Как получить GA4 код

1. Зайди на analytics.google.com
2. Создай аккаунт → новый ресурс → тип: Web
3. Введи URL своего сайта
4. Скопируй Measurement ID — выглядит как G-XXXXXXXXXX
5. Скажи Claude: «Замени G-XXXXXXXXXX на G-твой-реальный-id в index.html»
6. Задеплой → через 24 часа увидишь первые данные

Без аналитики ты не знаешь работает ли сайт. Обязательно.

Вопросы и ответы
FAQ — то, что все спрашивают
Мне нужно уметь программировать?
Нет совсем. Я написала ноль строк кода вручную. Весь HTML, CSS и JavaScript писал Claude по моим описаниям. Единственное что нужно — уметь чётко объяснять словами что ты хочешь видеть на экране.
Сколько это стоит?
GitHub Pages — бесплатно навсегда. ffmpeg — бесплатно (open source). Lenis.js — бесплатно. Claude — есть бесплатный план. Домен (необязательно) — от 500 ₽/год. Итого базовый вариант: 0 ₽. Для сравнения: заказать сайт у фрилансера — от 30 000 ₽, у студии — от 150 000 ₽.
Можно ли сделать это на Windows?
Да. Установи Git for Windows (gitforwindows.org) — он включает Git Bash, который работает как терминал. ffmpeg тоже есть под Windows — скачай с ffmpeg.org. VS Code работает везде. Всё остальное (GitHub, Claude) — в браузере.
Что если Claude написал что-то неправильно?
Просто скажи ему что не так. «Это выглядит неправильно — кнопка перекрывает текст на мобильном» — и он исправит. Если совсем всё сломалось — можно попросить его «откатить последнее изменение и сделать иначе». Claude помнит контекст разговора и понимает что именно менялось.
Как добавить свой домен типа andreyana.ru?
1. Купи домен на reg.ru, namecheap или любом регистраторе (~500–1500 ₽/год). 2. В настройках домена добавь DNS-записи типа A, указывающие на серверы GitHub (их четыре IP, они есть в документации GitHub). 3. В репозитории Settings → Pages → Custom domain — введи свой домен. 4. Подожди до 24 часов пока обновится DNS. Готово.
Можно ли сделать не медиакит, а другой сайт?
Конечно. Этот же процесс подходит для: портфолио фотографа, сайта бьюти-мастера, лендинга для курса, персонального сайта-резюме, сайта небольшого бренда. Ключевое — нужно знать что ты хочешь и уметь описать это словами Claude.
Что если GitHub Pages работает медленно?
Главное для скорости — сжатые видео и оптимизированные фото. Используй ffmpeg для видео (crf 28) и squoosh.app для фотографий (WebP формат, качество 80%). Если всё равно медленно — можно подключить Cloudflare CDN бесплатно, он кеширует файлы по всему миру.
